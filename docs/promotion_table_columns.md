# Таблица кандидатов и карточка товара

Кнопка «Настройка колонок» над таблицей выбирает видимые колонки без повторного расчёта. Сохраняется только список ключей колонок в localStorage `promotion-candidates-columns-v2` текущего браузера/устройства, без данных товаров. Неправильное/недоступное хранилище безопасно возвращает настройки по умолчанию. Остаётся минимум одна колонка. Настройки не изменяют Excel и расчёт отчёта.

По умолчанию видимы фото, товар, сезонность, сезонный приоритет, причины, остаток Авиаторов Зал+Склад и статус. Все остальные поля доступны в настройках. Таблица имеет фиксированную раскладку на 100% доступной ширины, текст и метки переносятся; включение всех полей на маленьком экране увеличит высоту строк. Значок i у каждого заголовка имеет нативную hover-подсказку с описанием.

При открытии карточки выполняется один запрос POST /reports/promotion-candidates/product-catalog только для одного code/article. Используются текущий batch-info и существующий кеш. Возвращаются компактные остатки по именованным складам и характеристика с точным названием «Менеджер ОЗ» (верхнеуровневое поле, properties или attributes). Другие менеджеры не подставляются. При отсутствии этого поля отображается «Нет данных»; если источник его не передаёт, понадобится согласование контракта VRCatalog.

Основной набор отчёта не содержит всех складов/характеристик всех товаров, не увеличивается его массовая проекция. Новый запрос использует существующую защиту тяжёлых маршрутов и RAM. При закрытии/смене карточки браузерный запрос отменяется, устаревший ответ не обновляет карточку. Ошибка API показана отдельно, без токенов и автоматических повторов; браузерная отмена не гарантирует остановку серверного запроса. Миграции/настройки production не требуются и не выполнялись.

Колонка «Менеджер» берётся из одноимённой характеристики VRCatalog, не из Clients VR и не из «Менеджер ОЗ». Присоединяется из уже загруженного batch-info/кеша без нового запроса. Есть в таблице и обоих Excel-экспортах. При первом переходе с настроек колонок v1 сохраняется прежний выбор и добавляется новая колонка; далее её можно скрыть как остальные. Нет характеристики — «Нет данных».
