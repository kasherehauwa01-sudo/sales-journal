# Закрепление заголовка и экспорт выбранных кандидатов

Шапка таблицы закрепляется у верхней границы окна при прокрутке строк. Заголовок страницы не закреплён; overflow у контейнеров таблицы не перехватывает viewport sticky. В первой колонке таблицы — флажки товаров; общий флажок выбирает/снимает все строки **текущей таблицы** (до 300), а не весь набор отчёта. Частичный выбор обозначен промежуточным состоянием общего флажка. По умолчанию и после нового успешного формирования/смены вкладки все сняты. Выбор не сохраняется на устройстве; сохранение настроек видимости колонок остаётся прежним.

При непустом выборе появляется «Скачать XLS (N)». Файл имеет корректный современный формат `.xlsx`, поддерживающий встроенные изображения. Экспорт включает все 16 содержательных колонок таблицы независимо от настройки видимости; флажки выбора служебные, не экспортируются. Порядок совпадает с текущей сортировкой таблицы. Существующая общая выгрузка остаётся доступной отдельно.

Новый POST `/reports/promotion-candidates/export-selected` получает ограниченный снимок выбранных строк (1–300). Не пересчитывает датасет и не обращается к БД/каталогу за характеристиками. Снимок отражает последний показанный отчёт, а не новое состояние продаж/остатков. Он не используется для изменения БД или утверждения акции. Сервер валидирует поля/количество/конечные числовые значения; текст записывается в Excel как строка, не формула. Интерфейс использует общую защиту выполнения/отмены/двойного нажатия; ошибки не запускают автоповторы.

Фотографии вставляются как изображения, а не ссылки. Поддержаны публичные HTTP(S)-адреса и до трёх безопасных перенаправлений, включая CDN. DNS проверяется при каждом переходе: все адреса должны быть публичными; соединение фиксируется на проверенном IP, исходный hostname используется для Host/SNI и проверки TLS. Private/loopback/link-local, credentials, нестандартные порты, proxy из окружения и HTTPS→HTTP перенаправления не допускаются. Bearer-токен не отправляется.

Лимиты сохранены: последовательная загрузка, до 2 МБ и 4 млн пикселей, timeout до 3 секунд, общий бюджет 15 секунд (+незавершённое socket чтение; DNS зависит от системного resolver), миниатюры до 96×72. Повторяющиеся URL обрабатываются один раз. Если у товара нет URL, в ячейке «Нет фото». Если заявленное фото загрузить не удалось, экспорт возвращает понятную HTTP 502 и не выдаёт файл с подменой фото ссылкой; можно повторить вручную/выбрать меньше товаров. Реальный доступ к production-фото не проверялся.

В книге только лист «Выбранные товары», без листа «Информация». Шапка оформлена, есть автофильтр, закрепление первой строки/идентификаторов, чередование фона строк и числовой формат. Ширины рассчитываются до потоковой записи по заголовкам и данным. «Товар» ограничен шириной 70 символов, включён перенос и увеличивается высота строки; остальные колонки подбираются по содержимому (технический максимум Excel — 255 символов). Колонка фото рассчитана на миниатюру.

Временные исходники/миниатюры находятся в TemporaryDirectory и удаляются после сохранения/ошибки. write-only workbook сохраняет компактные миниатюры на диске, не оригиналы всех товаров в RAM. Общие guard тяжёлого маршрута, single-operation lock и ensure_headroom сохранены. Отмена браузера не гарантирует немедленной остановки run_cpu; существующий runtime удерживает защиту до завершения CPU-операции. Кеш/TTL/параллелизм/лимиты RAM не повышены.

Зависимость: Pillow==12.1.1 в backend/requirements.txt. После проверки PR необходимо обычное обновление backend-образа с установкой зависимости и frontend; миграций нет. Деплой/production-запросы не выполнялись.

Изолированный синтетический замер обновлённого оформленного файла (300 строк): без фото 350,64 мс / 58,82 МиБ пикового RSS / 23 595 байт; с 300 миниатюрами 564,80 мс / 62,29 МиБ / 96 260 байт. Это простые сгенерированные миниатюры, без сети и декодирования оригиналов; результаты не обещают аналогичной задержки production. Лимиты изображений и защита RAM сохранены.
