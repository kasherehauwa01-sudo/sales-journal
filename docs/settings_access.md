# Пароль администратора настроек

Раздел настроек защищён отдельным backend-паролем. Открытый пароль не хранится
ни во frontend, ни в БД, ни в `.env`: приложение получает только scrypt-хеш.

## Первичная настройка

Внутри backend-окружения выполните:

```bash
cd /app
PYTHONPATH=. python scripts/hash_settings_password.py
```

Скопируйте результат в `SETTINGS_ADMIN_PASSWORD_HASH`. Также создайте независимый
секрет подписи сессии:

```bash
openssl rand -hex 32
```

и сохраните его в `SETTINGS_ADMIN_SESSION_SECRET`. Не коммитьте эти значения.
После изменения переменных пересоздайте только backend-контейнер.

Сессия хранится в подписанной HttpOnly/Secure/SameSite=Strict cookie и действует
8 часов. После пяти неверных попыток с одного адреса вход блокируется на 15 минут.
