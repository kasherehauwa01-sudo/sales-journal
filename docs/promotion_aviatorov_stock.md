# Остатки Авиаторов Зал+Склад

В отчёте кандидатов добавлены отдельная колонка, сортировка и последний столбец Excel «Остатки Авиаторов Зал+Склад». Общий остаток и расчёт запаса по всем складам сохранены.

Критерий «Минимальный остаток Авиаторов Зал+Склад» сравнивается только с количеством в этом складе, включая сезонные рекомендации. Пустое поле передаёт null и отключает критерий; ноль — отдельный числовой порог. Общий нулевой остаток по-прежнему даёт стоп-фактор «Нет в наличии».

Используется существующий batch-info и его кеш, без новых запросов. Число извлекается из stocks/warehouse_stocks/balances. Поддержаны список warehouse/name с quantity/stock_quantity/value и словарь по имени склада. Имя сравнивается без регистра и лишних пробелов; склад «Авиаторов» сам по себе не включается. Неизвестное/нечисловое/нефинитное количество показано как «Нет данных», не подменяется нулём или общим остатком. При заполненном минимуме товары с меньшим или неизвестным остатком исключаются из отчёта, KPI и общей выгрузки; значение ровно на пороге проходит. Пустое поле отключает фильтр и возвращает в том числе товары с неизвестным остатком. Классификация остальных стоп-факторов сохраняется.

Миграции и изменение конфигурации не требуются. Деплой не выполнялся. Проверки изолированные, без production API/БД.
