# Поиск по папке в отчетах

Общий фильтр доступен в отчетах «Продажи по товарам», «Товарная аналитика»,
«Аналитика категорий», «Кандидаты в акцию», «Динамика продаж»,
«Аналитика по магазинам», «Сигналы · Shadow» и в публичном отчете HoReCa.
RFM-анализ не изменен.

Дерево, поиск, раскрытие веток и множественный выбор повторяют смысл фильтра
CatalogVR: выбор папки включает ее вложенные папки; несколько папок объединяются.
С остальными фильтрами результат пересекается. Сброс возвращает все папки.
В «Продажах по товарам» можно выбрать только папку без ручного списка товаров;
если список товаров задан, он дополнительно ограничивает выборку.

Для дерева используется `GET /filters/folders` настроенного CatalogVR.
Это свойство пути папки, а не категория и не `/integration/catalog-tree`.
Состав папок читается через `GET /products/search` с повторяющимся `folder`,
сортировкой по ID и полной пагинацией. Наличие на складе и исключение раздела YYY
выключены: исторические продажи должны учитывать также товары без остатка.
Нужна версия CatalogVR с поддержкой этого фильтра. Миграции БД не требуются.

GET-отчеты принимают повторяющийся параметр `folders`; POST-отчеты — массив
`folders` в теле запроса. Выбор сохраняется в снимке сформированного отчета,
детализации, сравнении периодов, Excel и PDF. SQL отбирает товарные строки по
нормализованной паре код/артикул с одним массивным параметром. Для смешанного чека
в выручку и количество входят только выбранные товары. Пустая выбранная папка
дает пустую выборку, а недоступный каталог — явную ошибку, без снятия фильтра.

Список пар кэшируется на 5 минут, максимум 16 наборов и 100 000 пар суммарно.
Одновременные запросы одного набора папок используют одну загрузку. При превышении
100 000 товаров предлагается сузить выбор. Кэш товарной аналитики учитывает
как выбранные пути, так и актуальный состав папок.

Старый отчет «Сезонность» удален в main и не восстанавливается этой доработкой.
Новый отчет «Сезонность категорий» не изменяется: его снимки агрегированы по категориям
без товарных идентификаторов, необходимых для точного отбора по папкам.
HoReCa отбирает товары сохраненного отчета, не меняет его содержимое.
«Сигналы · Shadow» отбирает клиентов с покупками выбранных товаров до даты среза
и в рамках подразделения опубликованного расчета. Показатели сигналов не
пересчитываются; это пояснение показано рядом с фильтром.
